## Preview on PC
Double-click `index.html` (keep the `assets` folder next to it). Or open `preview.html`, a single self-contained file.

## Preview on Android / iPhone
Copy `preview.html` to the phone (WhatsApp, Drive, email, USB) and open it in Chrome or Safari. All pages, CSS, JS and photos are embedded. Use the menu button to move between pages.

## Put it online
Upload the whole folder (all .html files, styles.css, script.js, assets/) to Cloudflare Pages, Netlify, GitHub Pages or any static host. Do not upload only preview.html.

## Files
index, about, auditorium, gallery, weddings, location, contact (.html) · styles.css · script.js · assets/ (optimised WebP + JPG photos, logo) · assets/originals/ (your untouched supplied photos and logo) · preview.html

## Notes
- The enquiry form stores nothing. It opens WhatsApp or the visitor's email app with the message pre-filled; it reaches you when they press Send there.
- Fonts (Cormorant Garamond, DM Sans) load from Google Fonts when online; Georgia / system fonts are the offline fallback.
- The Location page links to Google Maps; no embedded map because only a share link was supplied.
- The intro animation plays once per browser session. Animations respect "reduce motion".
